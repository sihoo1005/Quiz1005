자바스크립트 기초 학습 페이지

학습 노트

자바스크립트는 웹 페이지를 동적으로 만들어주는 언어입니다.
- prompt() : 사용자 입력을 받음
- document.write() : 화면에 출력
- parseInt() : 문자열을 정수로 변환
- Math 객체 : 난수 생성 등 수학 기능
- Date 객체 : 날짜와 시간 처리
- getElementById() : id로 요소 선택
- getElementsByClassName() : class로 요소 선택
- addEventListener() : 이벤트 등록
